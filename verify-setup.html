❓ Troubleshooting

If you don't see Login/Signup:

  1. Clear browser cache (Ctrl + Shift + R)
  2. Try Incognito mode (Ctrl + Shift + N)
  3. Check browser console for errors (F12)
  4. Verify you're opening index.html (not index-spa.html)

If sliding text doesn't show:

  1. Clear browser cache completely
  2. Check if CSS file is loading (F12 → Network tab)
  3. Verify style.css exists in the same folder
🚀 Open Main Website (index.html)

Remember to clear your browser cache before testing!
