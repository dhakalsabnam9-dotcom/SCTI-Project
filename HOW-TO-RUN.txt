========================================
TROUBLESHOOTING
========================================

Q: Login page doesn't show properly?
A: Make sure style.css is in the same folder

Q: Images not showing?
A: Check that logo files are in the same folder

Q: Can't login?
A: Make sure you select the correct User Type
   Username and password are case-sensitive

Q: Logout not working?
A: Click the logout button in the top right
