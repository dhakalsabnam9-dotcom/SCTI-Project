Security

Built Secure by Default

Every layer of the system is protected against common vulnerabilities

SQL Injection Prevention

All queries use PDO prepared statements — no raw SQL with user input.

Password Hashing

Passwords stored with PHP's password_hash() and verified with password_verify().

Role-Based Access Control

Every protected page checks session role — unauthorized access redirects to login.

HTTPOnly Session Cookies

Session cookies are HTTPOnly, preventing JavaScript access to session data.

Remember Me Token

Secure 30-day token stored in DB — not the password — for persistent login.

Account Status Check

Inactive accounts are blocked at login — no access even with correct credentials.

Getting Started

Installation Guide

Get the portal running locally in under 5 minutes

Requirements

Apache (XAMPP/WAMP)
PHP 7.4+
MySQL 5.7+
Modern Browser

  1. Clone / Copy the project

    Place the project folder inside your web server root (e.g. C:/xampp/htdocs/scti).

  2. Create the database

    Open phpMyAdmin, create a database named scti_school, then import database/setup/database-setup.sql.

  3. Configure the connection

    Edit includes/config.php with your database host, name, user, and password.

  4. Open in browser

    Navigate to http://localhost/scti and log in with the demo credentials above.

  5. Run migrations (optional)

    Apply SQL files in database/migrations/ for sample data and extra features.

# 1. Place project in web root
C:/xampp/htdocs/scti/

# 2. Import database
database/setup/database-setup.sql

# 3. Edit config.php
define('DB_HOST', 'localhost');
define('DB_NAME', 'scti_school');
define('DB_USER', 'root');
define('DB_PASS', '');

# 4. Open in browser
http://localhost/scti
Tip: Run migration files in database/migrations/ to add sample students, teacher columns, and other enhancements.
About the Project

Built for SCTI

A real-world system for a real institution

Sindhuli Community Technical Institute (SCTI) is a nonprofit technical institute in Sindhuli, Nepal — supported by DCC Sindhuli, Kamalamai Municipality, and CTEVT.

This portal was built to replace manual, paper-based processes with a unified digital system — covering everything from student enrollment and daily attendance to assignment grading and course material distribution.

The system serves three distinct user roles — Admin, Teacher, and Student — each with a tailored dashboard and exactly the tools they need. No bloat, no unnecessary complexity.

Sindhuli, Nepal CTEVT Affiliated Nonprofit Institute Open Source

No Framework Overhead

Pure PHP, MySQL, HTML, CSS, and Vanilla JS — fast, lightweight, and easy to deploy on any Apache server.

Multi-Role Architecture

Admin, Teacher, and Student each get a dedicated dashboard with role-specific features and access control.

Fully Responsive

Works on desktops, tablets, and mobile phones — no separate mobile app needed.

Secure by Default

PDO prepared statements, password hashing, RBAC, HTTPOnly cookies, and account status checks on every request.
